# Marketing evidence

These files are immutable research snapshots. Each filename includes the observation date. They preserve source metadata used to form the current strategy, but competitor behavior, repository activity, package data, website responses, and search results may have changed.

- `competitive-2026-10-10.json` contains selected competitive, repository, package, issue, and observability evidence.
- `search-discoverability-2026-10-10.json` contains the pre-rewrite website and search-discoverability audit evidence.

Revalidate a source before quoting it publicly. Add a new dated snapshot for a new research cycle; do not overwrite historical observations.
